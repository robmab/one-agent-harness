# Interview me (and plan)

> **CONCEPT:** everything that happens before writing code, in one skill. What's asked for and what's needed rarely match, and the cheap moment to find out is before coding; if the task is big, it gets a short plan the user approves before the first edit. It stops the agent from filling gaps by inventing them.
